# ATLA Submission Packet — Goldstonian Concordance Bible (GCB)

This repository prepares the submission materials for the Goldstonian Concordance Bible (GCB) for theological indexing consideration through DigitalGeorgetown and ATLA-related discovery pathways.

## Primary Work

**Title:** The Goldstonian Concordance Bible: Canonical Structure, Ethiopian Orthodox Reception, and Machine-Readable Theology  
**Author:** Dr. Justin Goldston  
**Institutional Affiliation:** Georgetown University  
**Project Ecosystem:** SydTek University / SydTek Scholars / Goldstonian Concordance Bible (GCB)

## Purpose

This packet positions the GCB as a scholarly theological reference work and digital biblical studies infrastructure project. The submission emphasizes:

- The 81-Book Ethiopian Canon
- The Book of Enoch and Second Temple literature
- Canonical concordance methodology
- Digital theology and machine-readable religious scholarship
- DOI-backed preservation through Zenodo and related repositories
- GitHub-native version control for theological research

## Submission Targets

1. DigitalGeorgetown mediated deposit
2. Georgetown Library consultation
3. Theology and Religious Studies routing
4. ATLA visibility and indexing consideration
